# TXTphone

TXTphone is a text file editor website that you can use for create, view and edit a text file (.txt) content and file name.
It's allow for smartphone users that want to create, view and/or edit any text file (.txt) without download apps.
Obviously, you can access in PC or Laptop.

---

## Why this project (TXTphone) was created?

When I open the app *File* of my smartphone (Android) I can see that you can create folders like a PC.

And, I start to think "If I can create folder, Why I can't create files like .txt, .py or others?" "If I want to edit and/or view any text file in my smartphone (because I can't use my PC or Laptop in that moment), Do I need download an app for do it?"

And for thats resons, I created a text file editor website (TXTphone) for create, view and/or edit any text file from my smartphone easily.

---

## Good things about this project (TXTphone)

- Can you use TXTphone in yout smartphone (Any OS)
- Can you create and save a text file.
- Can you view a text file.
- Can you edit and save a text file.
